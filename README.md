
# Student Management System

## About
A Python-based project to manage student records.

## Features
- Add student details
- View student details
- Store name, USN and marks
- Simple menu-driven interface

## Technologies Used
- Python 3

## Concepts Used
- Lists
- Dictionaries
- Functions
- Loops
- Conditional statements

## How to Run
1. Install Python 3.
2. Open the project folder.
3. Run:

python student_management.py
